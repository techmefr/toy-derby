# Toy Derby

A compact tabletop-inspired toy racing and prediction game for 2–4 players on one device. Predict the finish order, spend stars on cards, and watch the chaos unfold.

## Prototype V0

One 24-space track, four distinct toys, twelve race events, twelve purchase cards, secret predictions, and one or three races. Compare scoring-only mode with track traps enabled. No real money or online multiplayer.

Open index.html in a browser. For GitHub Pages, select main / root in repository Pages settings.

## Mobile play
Play in landscape orientation. Portrait mode displays a rotation prompt without resetting the current game. Desktop uses a responsive race cockpit.
