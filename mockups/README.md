# Interface mockups

Desktop: track and racer positions on the left; current die, event, actions and race log on the right. Mobile: stack track above controls, use large touch targets and a compact scoreboard. Secret predictions use a dedicated handoff screen. Art direction: colorful Japanese 16-bit toy racing, one oval track, readable 24 spaces, patterned toy sprites. Future mobile-only mode may use automatic side-view racing with a radar. No extra tracks or cosmetic purchases in V0.
