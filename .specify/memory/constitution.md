# Toy Derby Constitution

1. Fun and prediction tension come before simulation complexity.
2. Keep the physical and digital rules aligned.
3. Same-device play, mobile-first responsive layout, no accounts.
4. Isolate experimental mechanics behind independent feature flags.
5. Keep the initial physical kit inexpensive: foldable A4 track, reference sheet, cardboard standees, mini cards, stars and secret slates.
6. Collect anonymous playtest feedback only with consent. Never expose credentials in a static site.
7. Keep source, documentation and commits in English.
